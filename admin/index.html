    Sign in to edit

    Everything in the Hub works without signing in. To change your website (prices, banners, courses) you need your GitHub key. It's saved only on this phone or computer.

    How to make your GitHub key (one time, about 2 minutes)

    1. Open GitHub → new fine-grained key (signed in as thegirlsclub246).
    2. Name: TGC admin. Expiration: 1 year (custom).
    3. Repository access: Only select repositories → thegirlsclub246.github.io.
    4. Permissions → Repository: Contents: Read and write. Optional: Pages: Read (shows if your change is live).
    5. Tap Generate token, copy it, paste it above.

    Keep it private like a password. Lost phone? Delete the key on that same GitHub page and make a new one.
